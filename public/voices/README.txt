Voxel Heroes NPC recordings

Original game dialogue generated locally with Kokoro; mono Opus VBR 32 kbps.
The runtime ships audio clips only. Model weights and synthesis libraries are
development tools and are not included in this directory or the game bundle.

Recorder: kokoro-js 1.2.1
https://github.com/hexgrad/kokoro/tree/main/kokoro.js
Model: onnx-community/Kokoro-82M-v1.0-ONNX (Apache-2.0)
https://huggingface.co/onnx-community/Kokoro-82M-v1.0-ONNX

Source inventory and character voice assignments: assets/voices/inventory.json
Shipped take IDs and SHA-256 receipts: src/game/voice-bank.json
Human listening review can be built with scripts/build-voice-review.mjs.
